## Build a template

`POST /templates/build`

Starts a template build in the background and returns immediately. Poll `GET /templates/{template_id}` to check when it's ready. Submitted Dockerfiles run in disposable jailed VMs with private caches; host services, private networks and cloud metadata are unreachable.

**Request body**

```json
{
  "name": "my-python-env",
  "dockerfile": "FROM python:3.11-slim\nRUN pip install numpy pandas",
  "rootfs_size_mb": 500
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `name` | string | required | Human-readable name |
| `dockerfile` | string | required | Full Dockerfile contents |
| `rootfs_size_mb` | int | `500` | Rootfs image size in MB, from 64 to 16384 |
| `tenant` | string | Caller's sole tenant, otherwise `default` | Owner of the resulting template |

A token scoped to several tenants must specify one. A build for an existing template cannot change its owner. Invalid sizes return `400`; a concurrent build of the same ID returns `409`. Deleting a template while its build runs also returns `409`.

Builds require host Docker for the trusted appliance. Each builder has 2 vCPUs, 2 GiB of guest memory, a bounded private disk and a 15-minute command deadline. `FLINT_BUILD_CONCURRENCY` limits simultaneous builders (default `1`, valid range `1`–`4`). After a daemon crash, abandoned builders are stopped and wiped before new requests are accepted.

**Response** `200`

```json
{
  "template_id": "tpl_abc123",
  "status": "building"
}
```

## List templates

`GET /templates`

**Response** `200`

```json
{
  "templates": [
    {"template_id": "default",   "name": "Default",        "status": "ready"},
    {"template_id": "tpl_abc123","name": "my-python-env",  "status": "ready"}
  ]
}
```

---

## Get template

`GET /templates/{template_id}`

**Response** `200` or `404`

```json
{
  "template": {
    "template_id": "tpl_abc123",
    "name": "my-python-env",
    "status": "ready"
  }
}
```

Status values: `"building"`, `"ready"`, `"failed"`

---

## Delete a template

`DELETE /templates/{template_id}`

You can't delete the `"default"` template.

**Response** `200`

```json
{"ok": true}
```

**Response** `400` - if you try to delete `"default"`

**Response** `404` - template not found
